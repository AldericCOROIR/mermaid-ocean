# Castle v2 paint-over prompts

Generated with the built-in image generation tool. Each first reference was a clean,
raw screenshot from the named camera in `castle_cams.json`; the second reference
was the prior painted Coralia style plate. The first image defined the geometry
and perspective; the second supplied only the painted style. The five outputs
are preserved here as `castle_*_v2.png` and resized for the game in
`assets/paint/castle_*_v2.jpg`.

## Gate

gate opening, two gate towers, outer walls and crenellations, distant palace
dome and towers, foreground sand, and view through the gate. Make the wall
read as a majestic mermaid fairy-tale castle enclosing a little city. Add
gouache brush strokes, shell ridges, pearly glints, coral motifs, saturated
turquoise water, pink/lilac masonry, and golden accents. Do not move or close
architecture, change perspective, or add characters, UI, or text.
